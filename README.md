
# SmartBooking Version 2

UI prototype and project scaffold for the AI-Powered Styling System for Nails & Body Worx Services Management.

## Technology Plan

- Core frontend: HTML, CSS, JavaScript
- Core backend: PHP
- Database: MySQL
- AI modules: Python only

## Setup in XAMPP

1. Extract the `smartbooking_v2` folder.
2. Copy it to `C:\xampp\htdocs\`.
3. Start Apache in XAMPP.
4. Open:
   `http://localhost/smartbooking_v2/`

## Important

This package is currently a UI prototype. Login, booking, payment, reports, and AI buttons use demo behavior only. Backend and database logic will be added after requirements, workflows, ERD, and data dictionary are approved.
